# DevKit

一个**完全离线**的开发者文本工具集。打开 `index.html` 就能用，不需要安装、不需要联网、没有后端 —— 所有转换都在浏览器里完成，粘进去的内容不会离开你的电脑。

> 做它的原因很简单：JSON 格式化、Base64 解码、JWT 看一眼 payload、算个哈希，这些事每天都要做几次，但每次都要去搜一个在线工具，然后把剪贴板内容贴给一个不认识的服务器。

## 工具

| 工具 | 做什么 | 快捷键 |
| --- | --- | --- |
| **JSON** | 实时格式化 / 压缩，语法错误定位到行列 | `⌘1` |
| **Base64** | 文本与 Base64 互转，支持 URL 安全字符集 | `⌘2` |
| **URL** | 编码、解码、把查询串拆成键值对 | `⌘3` |
| **时间戳** | 秒 / 毫秒 / 日期互转，自动识别 10 位或 13 位 | `⌘4` |
| **哈希** | SHA-1 / SHA-256 / SHA-512 | `⌘5` |
| **命名** | camelCase、PascalCase、snake_case、kebab-case、CONSTANT_CASE、Title Case | `⌘6` |
| **正则** | 实时匹配并高亮，列出每个分组 | `⌘7` |
| **字数** | 字符、词、行、中文字数、UTF-8 字节 | `⌘8` |
| **JWT** | 解出 header / payload，检查是否过期 | `⌘9` |

## 快捷键

- `⌘K` — 命令面板，搜索并切换工具
- `⌘1` ~ `⌘9` — 直接跳到对应工具
- 面板里 `↑` `↓` 移动，`↵` 进入，`Esc` 关闭

## 运行

```bash
git clone <this-repo>
cd devkit
open index.html
```

没有构建步骤，没有依赖，没有 `npm install`。也可以直接把它部署到任意静态托管（GitHub Pages、Vercel、对象存储）。

## 设计取舍

- **不联网**：哈希用 `crypto.subtle`，编码用 `TextEncoder`，全部在本地跑。这不是一个「把内容发给服务器再拿回来」的工具。
- **零依赖**：没有框架、没有打包器。三个文件，改了就能生效，五年后打开还能跑。
- **键盘优先**：手不用离开键盘就能在工具之间跳。
- **中文按字计**：中文没有空格分词，所以中文字数和英文词数分开统计，不混成一个「字数」。

## 浏览器支持

Chrome / Edge / Safari / Firefox 的当前版本。`navigator.clipboard` 在 `file://` 下可能被限制，用本地服务器打开即可：

```bash
python3 -m http.server 8080
```
